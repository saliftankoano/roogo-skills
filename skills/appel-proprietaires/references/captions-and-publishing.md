# Social captions, tracking, and naming

## The caption document

Deliver the social copy as a French document, generated with `python-docx` and
using the brand colors on headings. It contains, in order:

1. the video title;
2. the short-form caption with hashtags, for vertical video platforms;
3. the page post for the brand's own page;
4. a repost variant for local real-estate groups, including an explicit ask to
   share;
5. publishing notes: where each variant goes and anything the poster must
   check first.

Every caption on every platform must carry the site link on its own line near
the phone number, for search visibility. This caption document is the one
Roogo deliverable where emoji are allowed, because staff copy and paste it
directly; all other copy stays free of emoji, and no copy uses em dashes.

## Publishing tracking

Deliver into a dated campaign folder that contains a `publie/` subfolder, and
create that subfolder with every new bundle. Files sitting in the folder root
are not yet posted. When the requester confirms something was posted, move
those files into `publie/`. The folder layout is the posting record, so do not
leave it ambiguous.

## Naming

Final assets get real French titles, for example `Roogo - <hook>.mp4` and
`Roogo - <hook>.png`, because platforms use the filename as the default upload
title. No code-style slugs, no em dashes, no emoji in filenames.
